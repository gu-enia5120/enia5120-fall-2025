Week 2: September 16

Reading:
IMS Chapters 1, 3, 4-6. I don’t expect you to know this before class, but work through this material this week. Especially Chapter 3, which gives a pretty good on-ramp to R.

You can also look at RDS Chapter 10, which is not quite as insightful

Also, let’s start thinking about using Quarto (https://www.quarto.org) for our work in this class rather than Word or something like that. Data analysis is necessarily computational and so we need a good way to incorporate our analyses into our documents; that is Quarto.

  1. Install Quarto from https://quarto.org/docs/get-started/
  2. Follow along the tutorial at your own pace to get a feel for Quarto documents https://quarto.org/docs/get-started/hello/rstudio.html

The plan for class is to on-ramp you to , using examples and labs, with a focus on exploratory data analysis. So please ensure that you have access to . We will go slow and steady, since I know some of you have trepidation around this aspect of the class. Think of this as a language to learn and explore, with a limited vocabulary and grammar.

There will be a quiz this week, to familiarize yourselves with the syllabus. We will have a homework and labs this week to help you acclimatize to

Week 3: September 23

This week, we will basically hold a workshop covering (broadly) the material in RDS 1-8. In terms of reading, take a look at these chapters to start familiarizing yourselves with the language. The plan will be to show you how to do something, reinforce it with short worksheets, and then address questions around the code and how you might achieve something you want to do.

In terms of deliverables, we will not have a quiz this week, but we will have an -based homework using scaffolded code chunks and Quarto.

Important

Philosophically, the software and coding, regardless of the tool involved, is just a tool in service of your overall purpose, be that scientific or narrative. So I would like you think about coding not as a major hurdle but as a way to achieve something you conceive of to generate and enhance insight from the data. To quote Stephen Covey, “Begin with the End in Mind”.

What is primary is what you want to achieve with the data.

Then, and only then, do you try to figure out how to use the software tools to achieve that.

TipSupplementary materials
  • Tidy Data by Hadley Wickham
  • The Very Basics, from Hands-On Programming with R by Garrett Grolemund (free online)
  • Data Wrangling from ModernDive by Chester Ismay and Albert Y. Kim (free online)
  • Efficient workflow from Efficient R Programming by Colin Gillespie and Robin Lovelace (free online)
  • Posit cheatsheets (especially forcats, lubridate, stringr, dplyr, ggplot2)
  • Project Structure by Danielle Navarro
  • Data Import with readr (RDS Chapter 6)
  • Data Transformation with dplyr (RDS Chapter 5)
  • Data Cleaning with tidyr (RDS Chapter 4) (we will not cover this in detail this week, but you should be aware of it)
  • Data Visualization with ggplot2 (RDS Chapter 3)

Week 4: September 30

This week, we start exploring the world of statistical pattern recognition, and think about the kinds of models and algorithms can help us identify patterns in data. We’ll start distinguishing between explanatory and predictive modeling, and think about the kinds of questions we can answer with models. We’ll also distinguish between unsupervised and supervised learning.
