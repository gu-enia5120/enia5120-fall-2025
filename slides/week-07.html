Lecture 7

Statistical Inference: Simulation-Based Methods

Simulating studies

Scenario

In the state of South Carolina, there is a concern that young people of working age (20-35) are leaving the state for better opportunities elsewhere. Around 15% of this age group own homes, compared to a national average of 20%. Home-owners have a 1% chance of leaving the state, while renters and non-home-owners have a 15% chance of leaving the state. A new program is being considered to provide incentives for young renters to stay in the state. The program will cost $1000 per person who takes it up, and is expected to reduce the chance of leaving the state from 15% to 10%. It is expected that 30% of renters will take up the program. The average cost of a person leaving the state is estimated to be $50,000 in lost tax revenue and economic activity. We will simulate the impact of this program on a population reflecting the population of South Carolina in 2019, using usdata::pop_age_2019.

Simulations are most often based on conditional probabilities

If this, what is the likelihood of that?

There is intrinsic variability in consequences

  • If there was surety (likelihood = 100%), we wouldn’t need simulations
  • What we will often think about is, how variable are the consequences?

Categorical outcomes

If there is a small set of possible consequences:

  • Yes/No → Binomial(1, p) where p=P(Yes) → rbinom
  • Mutually exclusive outcomes → Multinomial(1, p), where p is a vector of probabilities summing to 1 → rmultinom
  • If not mutually exclusive, needs more thought.
    • Usually split into two correlated categoricals where you work out the joint distribution

Continuous outcomes

Symmetric → Normal (\(\mu,\ \sigma\))

  • More uncertain → larger \(\sigma\)
  • rnorm

Long right tail → Gamma (\(\alpha,\ \beta\))

  • rgamma

Continouous outcomes (contd.)

Continuous between 0 and 1 → Beta (\(\alpha,\ \beta\)) - rbeta

Many other choices possible, depending on the situation.

implementations: see the Distributions Task View on CRAN.

Running many simulations

First, encapsulate the logic in a function:

N <- usdata::pop_age_2019 |>
  filter(state == "SC", age >= 20, age <= 35) |>
  pull(population) |>
  sum()

sim_function <- function(N) {
  behavior_now <- tibble(homeowner = rbinom(N, 1, 0.15)) |>
    mutate(leaves = ifelse(homeowner == 1, rbinom(n(), 1, 0.01), rbinom(n(), 1, 0.15))) |>
    mutate(cost = leaves * 50000)

  intervention <- tibble(homeowner = rbinom(N, 1, 0.15)) |>
    mutate(takes_program = ifelse(homeowner == 1, 0, rbinom(n(), 1, 0.3))) |>
    mutate(leave_prob = case_when(
      homeowner == 1 ~ 0.01,
      takes_program == 1 ~ 0.10,
      TRUE ~ 0.15
    )) |>
    mutate(leaves = rbinom(n(), 1, leave_prob)) |>
    mutate(cost = leaves * 50000 + takes_program * 1000)

  total_cost_now <- sum(behavior_now$cost)
  total_cost_intervention <- sum(intervention$cost)
  return(data.frame("now" = total_cost_now, "intervention" = total_cost_intervention))
}

Duality between confidence intervals and hypothesis tests

Estimation and hypothesis testing

  • Confidence intervals provide a range of plausible values for a parameter
  • Hypothesis tests assess the evidence against a null hypothesis about a parameter

Duality

  • A 95% confidence interval for a parameter includes all values that would not be rejected by a two-sided hypothesis test at the 5% significance level
  • Conversely, if a value is outside the 95% confidence interval, it would be rejected by the corresponding hypothesis test

Duality (contd.)

Let’s consider a random sample of size 100 from DC (using the data from last week). We want to test whether the mean age in DC is less than 35 years.

Under the null hypothesis \(H_0: \mu = 35\), we can perform a one-sample t-test:

Code 
n <- 1000
p <- t.test(sample_1000$age, mu = 35, alternative = "less")$p.value

tibble(group = 1, mean = 35, sd = sd(dc_pop$age) / sqrt(n)) |>
  ggplot(aes(xdist = dist_normal(mean, sd), fill = stat(x < mean(sample_1000$age))), show.legend = F) +
  stat_halfeye() +
  scale_fill_manual(values = c("TRUE" = "red", "FALSE" = "lightblue")) +
  annotate("text", x = 30, y = 0.4, label = paste("p =", round(p, 4)), size = 3) +
  labs(x = "Age") +
  theme(axis.title.y = element_blank(), axis.text.y = element_blank(), legend.position = "none")

Permutation test

When we’re trying to determine if there is a significant difference between two groups, we can use a permutation test. Under the null hypothesis of no difference between two groups, the group labels are interchangeable, since we are assuming the two distributions are the same.

A permutation test involves:

  1. Calculating the observed difference in a statistic of interest between the two groups.
  2. Randomly shuffling the group labels and recalculating the difference in the statistic.
  3. Repeating this process many times to create a distribution of the differences under the null hypothesis.
  4. Comparing the observed difference to this null distribution to calculate a p-value.

Important

We are not making any assumptions about the distributions of the data, or restricting ourselves to the statistics we can use. This makes permutation tests very flexible and robust, and allows us to compare different parameters between groups even if there are no “standard” tests available.

This is a general approach where we can compare groups using any statistic of interest, rather than restricting ourselves to standard tests like the t-test which only compare means.

Running a permutation test

To perform a permutation test, we’d do, say, 1000 random shuffles, and then compute the difference in the group means based on the shuffled labels each time.

n_permutation <- 1000
set.seed(2894)
difference_perms <- replicate(n_permutation, {
  shuffled_labels <- sample(emissions_data$filter)
  mean_A <- mean(emissions_data$reduction[shuffled_labels == "A"])
  mean_B <- mean(emissions_data$reduction[shuffled_labels == "B"])
  return(mean_B - mean_A)
})

Resampling-based confidence intervals

Bootstrapping

How can we get assumption-free confidence intervals directly from our sample data?

  • Resample with replacement from the observed data to create “bootstrap samples”
  • Calculate the statistic of interest for each bootstrap sample
  • Use the distribution of bootstrap statistics to estimate confidence intervals

It turns out that this bootstrap approach results in a distribution that approximates the sampling distribution of the statistic. For not-too-small samples, this works well in practice.

Example: bootstrap confidence interval for mean age in DC

Code 
set.seed(975)
n_bootstrap <- 5000
bootstrap_means <- replicate(n_bootstrap, {
  sample_data <- sample_1000$age |>
    sample(size = nrow(sample_1000), replace = TRUE)
  mean(sample_data)
})
ci_bootstrap <- quantile(bootstrap_means, probs = c(0.025, 0.975))
tibble(bootstrap_mean = bootstrap_means) |>
  ggplot(aes(x = bootstrap_mean)) +
  geom_histogram(fill = "lightblue", color = "black") +
  labs(
    title = "Bootstrap Distribution of Mean Age",
    x = "Mean Age",
    y = "Frequency"
  ) +
  geom_vline(xintercept = ci_bootstrap[1], color = "red", linetype = "dashed") +
  geom_vline(xintercept = ci_bootstrap[2], color = "red", linetype = "dashed") +
  annotate(
    "text",
    x = ci_bootstrap[1] - 1,
    y = 50,
    label = paste("2.5% =", round(ci_bootstrap[1], 2))
  ) +
  annotate(
    "text",
    x = ci_bootstrap[2] + 1,
    y = 50,
    label = paste("97.5% =", round(ci_bootstrap[2], 2))
  ) +
  theme_minimal()

Bootstraps and sampling distributions

  • The bootstrap distribution approximates the sampling distribution of a statistic, especially its variability
  • We can use the bootstrap distribution to estimate standard errors, bias, and confidence intervals for the statistic
  • This is particularly useful when the sampling distribution is unknown or difficult to derive analytically
  • The bootstrap approach is flexible and can be applied to a wide range of statistics and data types

Bootstrapped standard error of the mean age in DC

Code

Comparing to the theoretical standard error of the mean:

[1] 0.6449374

and simulating the sampling distribution of the mean:

Code 
set.seed(975)
n_sim <- 5000
sampling_means <- replicate(n_sim, {
  sample_data <- dc_pop$age |> sample(size = nrow(sample_1000))
  mean(sample_data)
})
se_simulated <- sd(sampling_means)
se_simulated
[1] 0.6394295

This is quite useful for planning studies, when you might have a small pilot data in hand. As we’ll see next, we can use this to figure out how large a sample size we need to achieve a desired power for hypothesis tests. A good estimate of variability (uncertainty) is crucial for this.

Some caveats

  • Bootstrap methods assume that the sample is representative of the population, and that the sample is a random sample from the population.
  • Bootstrap methods may not perform well for small sample sizes, especially for statistics that are not smooth functions of the data (e.g., medians, quantiles). We need enough data to capture the variability in the population.
  • Bootstrap methods may not perform well for data with strong dependencies or complex structures (e.g., time series, spatial data).

There are various variations of the bootstrap method we describe here (which is often called the naive bootstrap). These may improve things in certain situations, but the naive bootstrap works well in many practical scenarios. Find your friendly neighborhood statistician if you need help!

Sample size and Power analysis

How do we figure out the right sample size for a study?

  • Need to consider:
    • Effect size (to detect)
    • Significance level (alpha)
    • Power (1 - beta)
    • Variability in the data (standard deviation)

Strategy

  • Recall that we can increase power by reducing the standard error of the mean (SEM) → increase sample size
  • For a particular sample size n, we can calculate value of the mean needed to achieve exactly the significnace level \(\alpha\) that is set.
  • Then, we can calculate the probability of observing a mean at least that extreme under the alternative hypothesis → this is the power.
  • We can vary n until we achieve the desired power.

Heuristics

  • Larger effect sizes require smaller sample sizes to detect, since the difference is more pronounced.
  • Higher significance levels (alpha) require smaller sample sizes, as we are more lenient in rejecting the null hypothesis.
  • Higher desired power (1 - beta) requires larger sample sizes, as we want to be more confident in detecting the effect.
  • Greater variability in the data (higher standard deviation) requires larger sample sizes, as the signal is harder to detect amidst the noise.

Example

Suppose we want to detect a difference in mean age of 6 years (from 35 to 41) with 80% power at a significance level of 5%. What sample size is needed?

library(pwr)
effect_size <- (41 - 35) / sd(dc_pop$age)
sample_size <- pwr.t.test(
  d = effect_size,
  power = 0.8,
  sig.level = 0.05,
  type = "one.sample",
  alternative = "greater"
)$n
sample_size
[1] 72.80538

We would need a sample size of approximately 73 to achieve this power.

But how would we do this using simulation?

set.seed(1234)
n_sims <- 1000
sample_size <- 50 # initial guess
power_simulation <- function(sample_size, n_sims, mu0, mu1, sd) {
  rejections <- replicate(n_sims, {
    sample_data <- rnorm(sample_size, mean = mu1, sd = sd)
    p_value <- t.test(sample_data, mu = mu0, alternative = "greater")$p.value
    return(p_value < 0.05)
  })
  power <- mean(rejections)
  return(power)
}
desired_power <- 0.8
current_power <- 0
while (current_power < desired_power) {
  current_power <- power_simulation(
    sample_size,
    n_sims,
    mu0 = 35,
    mu1 = 41,
    sd = sd(dc_pop$age)
  )
  if (current_power < desired_power) {
    sample_size <- sample_size + 5 # increment sample size
  }
}
sample_size
[1] 75

We would need a sample size of approximately 75 to achieve this power using simulation.
