Practicing with factors

The tidyr package provides a dataset from the 2017 American Community Survey (ACS) that contains information about the median household incomes and median monthly rents by state. The dataset is called us_rent_income. We plot a barplot of the medianan household income by state.

We can see that the states are ordered alphabetically. We can use the forcats package to change the order of the states to be in descending order of median household income. Find the right function in the forcats package to do this, and add it to the data wrangling step above. You can refer to the forcats documentation and forcats cheatsheet for help.

  • Exercise
  • Hint
  • Solution

Think of what you want to do with the states. Do you want to reorder them based on another variable? Do you want to change the order of the levels? Find a function that does that rather than trying to do it manually.

library(forcats) mydata <- us_rent_income |> mutate(state = fct_reorder(NAME, estimate)) ggplot(mydata, aes(y = state, x = estimate)) + geom_col() + labs(x = "Median Household Income", y = "State") + theme_bw()
